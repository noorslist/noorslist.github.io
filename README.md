# Noor's List event pages

One page per event for [Noor's List](https://sites.google.com/view/noorslist), the weekly schedule of Muslim community events in Central Florida.

Live at https://noorslist.github.io. Each event lives in its own folder (`<date>-<name>/index.html` + `flyer.jpg`). `data/events.json` lists every event and drives the home page. Pages are generated by `build_static.py` in the Noor's List tools folder.

## Visitor stats

Every page carries the GoatCounter snippet (dashboard: https://noorslist.goatcounter.com). `_tools/home_live.py` adds it to the homepage; after building event pages run `python3 _tools/analytics.py` to add it to any page missing it. Details in `_tools/analytics.py`.
